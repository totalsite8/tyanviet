# Vietsound — разбор источника, учебный продукт и план публикации

## 1. Решение по продукту

По уточнению заказчика сайт должен содержать сам курс, а не продавать его. Поэтому исходная промо-структура переработана в learner-first приложение: посетитель сразу попадает к урокам и учебным инструментам; нет цен, регистрации, заявок, CRM, коммерческого CTA или необходимости заводить аккаунт.

Название **Vietsound** сохранено потому, что оно принадлежит исходному сайту. Это не новое название, придуманное для проекта. Интерфейс ориентирован на англоязычного ученика вьетнамского; примеры и истории двуязычные.

## 2. Что использовано из первоисточника

Переданный Canva-сайт был оформлен как длинная страница Vietsound. В его содержании были разделы о знаниях/грамматике, TPR/TPRS-обучении, историях, преподавателях и отзывах, а также заявлена большая библиотека слов и историй. Footer содержал ссылки Terms & Support и Privacy Policy, подпись Canva и уведомление о данных Canva.

Публично индексируемые материалы `vietsound.net` описывают произношение, грамматику, TPR/TPRS и курсы. В описаниях встречаются курс произношения на 8 занятий и уровни Elementary / Intermediate / Advanced по 40 занятий. Эти коммерческие сведения в сайт не перенесены как предложение покупки: актуальность программы, лицензия и наличие полного исходного учебного контента должны быть подтверждены владельцем Vietsound до дальнейшего расширения.

Оригинальные бинарные изображения Canva получить из среды разработки не удалось (запрос к Canva завершался TLS-ошибкой). Поэтому в проекте есть подготовленное для сайта изображение `public/assets/vietsound-hero.jpg`, локальные CSS/SVG-иллюстрации и самостоятельная композиция footer. Исходные ссылки сохранены в [`docs/source-assets.md`](./docs/source-assets.md). Атрибуция Canva и их уведомление о данных намеренно не перенесены в footer React-сайта: они не описывают работу этой версии.

## 3. Текущая карта сайта

| Маршрут | Назначение |
|---|---|
| `/` | Dashboard: продолжение курса, локальный прогресс, блоки A1 и быстрый доступ к упражнениям |
| `/course` | Каталог 12 уроков, поиск и прогресс по четырём тематическим блокам |
| `/lesson/:lessonId` | Цели, слова, грамматические примеры, озвучиваемый диалог, тест, результат и переход между уроками |
| `/pronunciation` | Шесть тонов, визуальные контуры, звуковые пары, инвентарь звуков, tone quiz и запись/прослушивание собственного голоса |
| `/knowledge` | Поиск по словарю с нормализацией диакритики, фильтры, озвучивание, закладки и связанные грамматические темы |
| `/review` | Карточки сохранённых слов, повторение и self-rating «знаю / повторить» |
| `/stories` | Восемь коротких историй, поиск и фильтр по уровню |
| `/stories/:storyId` | Двуязычный текст, озвучивание, лексика и задание на понимание |
| `/progress` | Лучший результат и число попыток по каждому уроку, учебные дни, статистика, очистка данных и печать сводки после завершения курса |
| `/journal`, `/journal/:slug` | Четыре учебные заметки и страницы статей |
| `/about`, `/help` | Объяснение подхода и справка для самостоятельного ученика |
| `/privacy`, `/terms` | Фактическое описание работы локальных данных, speech synthesis и записи голоса |

Старые URL `/courses`, `/lessons`, `/tutors`, `/contact` перенаправляются на релевантные learner-first страницы. Остальные неизвестные адреса показывают 404.

## 4. Содержание учебной версии

- 12 последовательных оригинально структурированных A1-уроков, сгруппированных по четырём блокам.
- Каждый урок содержит учебную цель, лексику, объяснение грамматики, диалог и не менее трёх заданий.
- Проходной результат — 67%; повторная попытка разрешена, лучший результат сохраняется.
- Словарь объединён из слов курса с устойчивыми ID, поиском по словам/английским значениям/примерам и бездиакритическим запросом.
- Восемь стартовых TPRS/reading-историй имеют построчные переводы, словарь и вопросы на понимание.
- Четыре краткие заметки служат дополнительным чтением.

Это законченный стартовый A1-маршрут для самостоятельной практики в рамках данного набора данных, но не полная копия всей программы школы. Он **не содержит** полный архив из «2 000+ слов», «200+ историй», всех уровней, авторских аудиозаписей, учительского кабинета или синхронизации на сервере. Эти ограничения открыто указаны в README и не маскируются маркетинговыми заявлениями.

## 5. Архитектура и данные

- Стек: React 18, Vite, React Router, Lucide.
- Клиентское SPA без backend; данные учебного контента хранятся в исходниках `src/courseData.js` и `src/data.js`.
- Состояние ученика — один версионированный ключ `vietsound-learning-progress-v2` в `localStorage`: завершённые уроки и истории, лучшие результаты, попытки, сохранённые слова, учебные даты и повторение.
- Функция очистки удаляет локальный прогресс приложения. Никакие учебные события не отправляются на сервер.
- Web Speech API использует голос, установленный на устройстве; его акцент и качество не гарантируются. Запись голоса необязательна, запускается только по клику/разрешению, хранится во временной памяти вкладки и не загружается.
- Нет аккаунтов, платёжной формы, заявки, аналитики, внешней базы учеников, CRM или синхронизации между устройствами.
- Privacy/Terms страницы соответствуют именно этому client-only поведению и отдельно объясняют ограничения.

Перед размещением оригинальных историй, аудио, логотипов и коммерческих материалов владелец Vietsound должен подтвердить права на их использование. При добавлении backend/analytics/payment необходимо заново согласовать privacy и условия.

## 6. Проверки проекта

После интеграции основных страниц выполняются:

```bash
npm run build
npm test
```

Тесты проверяют полноту структуры A1-курса, уникальные ID слов, нормализацию поиска/ответов и правила обновления локального прогресса. Перед реальным публичным объявлением дополнительно следует проверить экранные состояния и звук на iOS/Safari, Android/Chrome, Firefox и desktop Chromium, а также клавиатурный доступ и режим печати.

## 7. Запуск и публикация

### Разработка и production preview

```bash
npm ci
npm run dev
npm run build
npm run preview -- --host 0.0.0.0
```

В dev/preview-сервере Vite разрешён доступ с preview-host Arena; приложение использует относительные URL и не делает браузерных запросов на `localhost`.

### Vercel

- Framework preset: Vite.
- Build command: `npm run build`.
- Output directory: `dist`.
- SPA rewrite уже задан в `vercel.json`, поэтому прямое открытие вложенного React Router URL возвращает приложение.
- Production deployment и пользовательский домен требуют импорта репозитория и выбора домена в Vercel-проекте.

### GitHub Pages

Workflow `.github/workflows/deploy-pages.yml` собирает приложение с `base=/tyanviet/`, копирует `index.html` в `404.html` как SPA-fallback и публикует Pages. Автоматический триггер — push в `main`, также доступен `workflow_dispatch`; перед публикацией нужно выбрать **Settings → Pages → GitHub Actions**.

## 8. Открытые задачи для будущего production-расширения

Это не блокирует самостоятельное прохождение реализованного A1-набора, но необходимо для коммерческого продукта школы:

1. Подтвердить у владельца, можно ли использовать название, учебные тексты и изображение; получить оригинальный логотип/файлы при необходимости точного совпадения с Canva.
2. Вычитать вьетнамские формулировки, варианты севера/юга, тоновые подсказки и английские переводы с преподавателем-носителем; аудио синтеза заменить утверждёнными авторскими записями, если это требуется.
3. Переносить дополнительные уровни и большие архивы только после получения и структурирования исходных материалов.
4. Если потребуется вход ученика — выбрать backend, модель хранения, аутентификацию, синхронизацию, экспорт/удаление данных и угрозозащиту; затем пересмотреть Privacy/Terms.
5. Провести ручной cross-browser/accessibility QA, Lighthouse, SEO metadata/OG, domain/HTTPS и мониторинг после выбора конечного хоста.
6. В production-деплое Vercel сначала проверить deployment preview, а затем назначить production domain; GitHub Pages публиковать после review через `main`.
