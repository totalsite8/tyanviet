# Vietsound — Learn Vietnamese

Адаптивный учебный сайт на React и Vite: не лендинг для продажи курса, а самостоятельный A1-путь для ученика. Можно открыть программу, проходить уроки, сохранять слова, тренироваться на историях и отслеживать прогресс без аккаунта.

## Быстрый запуск

Требуется Node.js 22.12+.

```bash
npm ci
npm run dev
```

Проверка production-сборки и тестов:

```bash
npm run build
npm test
npm run preview
```

## Что работает

- **A1-курс:** 12 последовательных уроков в четырёх учебных блоках: знакомство, кафе и числа, повседневная жизнь, повторение и диалог.
- **Интерактивные уроки:** цели, лексика, грамматическая заметка, озвучиваемый диалог и проверяемые упражнения; результат и лучший балл сохраняются локально. Урок засчитывается при результате от 67%.
- **Произношение:** шесть тонов, звуковые пары, инвентарь гласных/согласных, быстрый tone quiz, браузерное озвучивание и необязательная локальная запись голоса.
- **Словарь:** поиск по вьетнамскому/английскому слову и примеру, поиск без диакритики, тематические фильтры и закладки.
- **Повторение:** карточки сохранённых слов, отметка «знаю / повторить».
- **Истории:** восемь коротких двуязычных историй с построчным аудио, словарём и вопросом на понимание.
- **Прогресс:** завершённые уроки, лучшие результаты, попытки, учебные дни, завершённые истории, повторение слов и печатная сводка после завершения курса.
- **Дополнительные страницы:** учебные заметки, описание методики, помощь, privacy, terms и 404.
- **Доступность:** адаптивная навигация, семантические формы, состояния ошибок, keyboard shortcut `Ctrl/⌘ + K` в словаре и доступная альтернатива аудио в виде текста.

## Данные и ограничения

- Регистрация, оплата, CRM и backend не требуются и не реализованы: ни в одной странице нет продажной формы или воронки заявок.
- Прогресс, закладки и история повторений хранятся в `localStorage` текущего браузера и устройства; синхронизации между устройствами нет. Если очистить данные сайта, прогресс пропадёт.
- Озвучивание использует Speech Synthesis на устройстве, поэтому качество голоса `vi-VN` зависит от браузера и ОС.
- Запись голоса — необязательная browser-функция: микрофон запрашивается только после нажатия пользователем, запись остаётся во временной памяти страницы, не отправляется и очищается при выходе или удалении, если ученик сам не скачает файл.
- Этот релиз включает 12 учебных уроков, 8 стартовых историй и 4 заметки. Это **не** архив из «2 000+ слов» и «200+ историй», упомянутый в исходных материалах; заявления исходника не копируются как будто эти архивы уже перенесены.
- Бренд Vietsound сохранён по названию сайта-источника. Локальная фотография `public/assets/vietsound-hero.jpg` подготовлена для этого интерфейса; иллюстрации страниц и footer нарисованы в CSS/SVG. Получить бинарные оригинальные изображения Canva из среды разработки не удалось. Список исходных ссылок: [`docs/source-assets.md`](./docs/source-assets.md).

## Деплой

### Vercel

Импортировать GitHub-репозиторий в Vercel: Framework **Vite**, build command `npm run build`, output `dist`. `vercel.json` уже задаёт SPA rewrite, чтобы прямой вход на `/lesson/...` или `/stories/...` возвращал React-приложение. Для production-домена подключить проект в настройках Vercel.

### GitHub Pages

В репозитории включить **Settings → Pages → GitHub Actions**. Workflow `.github/workflows/deploy-pages.yml` собирает сайт с base `/tyanviet/`, добавляет SPA `404.html` и публикует его при push в `main` (или вручную через `workflow_dispatch`).

Для проверки локальной production-сборки:

```bash
npm run build
npm run preview -- --host 0.0.0.0
```

Подробности о первоисточнике, продуктовых решениях, архитектурных границах и следующих этапах — в [`PROJECT_PLAN.md`](./PROJECT_PLAN.md).
